# Kopma Unpas Digital Hub

Official modern responsive Company Profile web application for **Koperasi Mahasiswa Universitas Pasundan (Kopma Unpas)**.

## 🌿 Tech Stack
- **Framework**: [Next.js](https://nextjs.org/) (App Router) + TypeScript
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deployment**: Static & Node.js ready

## 🚀 Features (Fase 1 Frontend MVP)
- **Responsive Single-Page Layout**: Smooth scroll-spy navigation across `#home`, `#about`, `#gallery`, `#contact`, and `#location`.
- **Official Branding**: Forest Green (`#166534`) & Warm Gold (`#D97706`) with official Kopma Unpas emblem logo.
- **5 Business Units**: Toko Retail Tamansari, Toko Retail Lengkong, Green Cafe Tamansari, Fotokopi Setiabudhi, and Perdagangan Umum / Konveksi.
- **Interactive Bento Gallery**: Asymmetrical photo grid with category filters and lightbox view.
- **Interactive Google Maps**: Real-time embed for Kampus II Tamansari & campus directories.
- **Quick Contact Form & Clipboard Action**: One-click copy for Line, email, and secretariat details.
- **Fase 2 Previews**: Member Portal preview modal with NPM authentication mockup and Pre-registration membership flow.
- **Simulated AI SOP Chatbot**: Interactive floating drawer with Kopma Unpas FAQ knowledge base.

## 💻 Getting Started

### Prerequisites
- Node.js 18+ or later
- npm or pnpm

### Installation
```bash
# Clone the repository
git clone https://github.com/afsalprimamaula/Project-afsal.git

# Navigate to project directory
cd Project-afsal

# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build
```bash
npm run build
npm start
```
